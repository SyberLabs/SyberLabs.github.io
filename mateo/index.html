01 / AI developer tools · Python

GitHits design partnership

What I did

GitHits offered SyberLabs a design partnership. I designed the A/B pilot and its integration: a Python client for the GitHits API and the Claude Code wiring around it, with repository filters that keep our own code out of the evidence. Our coding-agent factory implemented both under host-run checks, and I reviewed and merged them.

The engineering decision

The integration routes Claude Code’s lookups through the client and records each call in the software running the test. This gives the test a record of tool use instead of relying on the AI assistant to report it.

Tested against a simulated GitHits service: requests, repository exclusions and lookup records. No live usage or savings are claimed.

02 / Hackathon, third place · Python

PorchLight

What I built

Drop a pin on a neighborhood problem and an agent finds who fixes it. It triages the note, finds the responsible San Francisco agency with cited Parallel search, drafts the report and posts the pin to a shared Sheet and Slack through Composio. I built it in one afternoon with the Cline coding agent at the Cline, Parallel & Composio Hackathon, where it placed third.

The engineering decision

A fixed pipeline with model steps inside it, not a free-roaming agent. The model may name an agency only when a search result it actually received supports it; otherwise the pin goes to a person. Reports are drafted, never sent, and emergencies skip the pipeline entirely.

03 / Lead developer · JavaScript

RISE

What I contributed

RISE lets readers experience text as a paced stream or a page, with sound and visuals. I led core development of text pacing and playback, moving graphics, browser audio, video export and automated tests.

Where my work fits

RISE is a team project. I collaborated with other contributors from the early application through later shared development. The recording above shows the reading and playback interface.

An example change, PR #643: a second voice under the same playback clock. Character timestamps from the speech service become word marks, playback runs through Web Audio, and the reader’s key stays in page memory. It adds 118 unit tests.

04 / Creative computation

Engines

Mathematics you can explore.

I built browser artworks that make mathematical rules visible and adjustable. In Gyre, those rules create a moving 3D trail of light. Change the starting pattern, shape and lighting to explore the result.

Gyre runs as a self-contained HTML file using the browser’s drawing tools. The recording shows one orbit; the live artwork lets you generate another.

Coding agents, held to checks

What I do

Much of my code is written with coding agents such as Claude Code and Cline. I decide what to build and how each change will be checked, then review what comes back before it merges.

What the checks do

At SyberLabs a change counts only when checks the host runs itself pass. An agent saying the tests pass is never enough. The GitHits client was built and admitted this way, and PorchLight was built with Cline in one afternoon.
