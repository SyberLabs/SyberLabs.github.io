01 / AI developer tools · Python

GitHits integration

What I built

A Python API client and Claude Code integration for a GitHits evaluation pilot: search, examples and source retrieval, with excluded targets refused before a request.

The engineering decision

Record lookups on the host rather than trusting an agent’s account of its own work. Contract tests use a local fake server. The integration is built and tested; measured savings are not established.
