Privacy

How this site handles your data.

syberlabs.io is a static website. Visitors get no accounts, web forms, tracking cookies, or third-party ad scripts. We use cookieless Cloudflare Web Analytics for aggregate page-view counts. The only login is an invite-only staff portal at /admin/.

Infrastructure
Served via Cloudflare Pages. As with any web delivery network, Cloudflare processes standard request metadata (IP address, user agent) to deliver pages and mitigate abuse.
Analytics
Cloudflare Web Analytics collects aggregate page-view and performance metrics via a lightweight beacon without cookies, local storage, or cross-site visitor tracking.
Fonts
All typefaces serve directly from syberlabs.io. Zero external font requests occur.
Video
RISE demo videos serve from syberlabs.io. The YouTube concept film embeds via youtube-nocookie.com and loads nothing until you press play.
Email
Contact links open your local mail client. SyberLabs receives only what you explicitly send and uses it strictly to reply.
Optional app backups
Signed-in users may explicitly save private backups from FLYSPACE (formerly Omni), RISE, or Sketch to Cloudflare D1 (document or canvas content, name, app, and save timestamp). No automatic sync occurs; local work remains in browser storage unless you select Save to account. Apps read only their own backups. Limits: up to 50 backups per account, 1 MB each, 10 MB total. Backups never store model API credentials or grant application permissions. Email contact@syberlabs.io anytime for deletion.
Invite-only staff sign-in
Authorized staff sign in via GitHub (numeric ID, username) and optionally Google (ID, email), stored with assigned roles and login timestamps in Cloudflare D1 alongside truncated IPs and browser names for audit logs. OAuth access tokens are never stored. Initiating sign-in sets a 10-minute cookie; authenticated sessions last 12 hours (13-hour cookie) strictly on syberlabs.io and can be checked by FLYSPACE, RISE, and Sketch via a restricted account endpoint. Visitors who never initiate sign-in receive zero cookies, and rejected logins leave no records. Audit logs retain for about 400 days; revoked accounts deactivate and delete upon request. Subprocessors: Cloudflare, GitHub, Google.
External links & products
Third-party sites (including GitHub and TypeSafe AI) follow their own privacy policies. The RISE reading app publishes a separate RISE privacy policy.
