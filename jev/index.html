AI integration / Case study

AI decisions with clear limits.

Structured AI answers. Rules in code. The reader stays in control.

See how it works

Historical case study of RISE’s integration of TypeSafe AI’s Jev, on a hosted path retired in September 2026. Jev is still available in RISE through the reader’s own OpenRouter account; see reader-owned AI in RISE. SyberLabs has no partnership with TypeSafe AI.

How Jev answers

Every AI decision has a fixed format.

Jev answers three kinds of questions: choose one option, estimate the probability of a yes-or-no condition, or rate on a scale. Select a type to see an example. The application’s own code still decides what is allowed.

      "choice": "experience_program",
      "confidence": 0.68,
      "probabilities": {
        "experience_program": 0.68,
        "agent_operation_set": 0.32
      }
    }
  }
}

Recorded Jev integration

One request. Many ways to read.

In the recorded Jev integration, readers described the reading they wanted. Jev chose a released text and passage, then configured the reader. RISE offered 23 sound options synthesized in the browser: gentle piano and jazz, six other keyboard styles from lullaby to ragtime, six cinematic themes, six mood beds, rain, and two ambient pieces. RISE validated every choice before playback.

Sound options were stored in PostgreSQL and briefly cached in Redis (retired September 2026). Jev received a short list matched to each request, so a growing catalog did not enlarge the set of options it chose from. Seven typefaces and five text sizes added visual range, and repeated open-ended requests rotated reading and presentation suggestions. A separate AI composition feature, the Scriptorium, has not yet been independently verified.
