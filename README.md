# SyberLabs homepage

Company and portfolio site for [syberlabs.io](https://syberlabs.io/).

Built with React and Vite on the SyberLabs design system v1 (dark only). `src/syberlabs.css` holds the tokens and shared components (header, buttons, project rows, status badge, footer); the homepage imports it and the build emits it at `/syberlabs.css` for the static pages. Project data and navigation live in `projects/site-data.js`, shared by the homepage and the project pages. Run `pnpm install` and `pnpm build:site` to generate the full Cloudflare Pages output in `dist/`. The public RISE demo is copied into `dist/rise-demo/` by the deployment workflow.

The **System maps** components (`src/system-maps/`, not rendered on the v1 homepage) draw Relay, OmniOS, RISE, Barn, OSAHR and SyberRuntime from their own repositories. Recorded traces in `src/*-trace.json` and `src/rise-record.json` are regenerated by the scripts in `scripts/`; `docs/SYSTEM_MAPS.md` records the evidence, commits and grades for every map.

The public COMMONS roadmap is maintained in `commons/index.html` and included in the same Cloudflare Pages deployment at `/commons/`. The homepage links directly to that route; the previous `/projects/commons/` address redirects there.

The current migration status lives in `kev/` and is published at `/kev/`. The prior Jev evaluation and integration case study remains at `/jev/` as historical evidence; its results must not be attributed to Kev.


The GrokCell Execution report lives at `research/jev-execution/`. It summarizes the durable offline prototype and its evidence limits; preserve the distinction between observed results and planned live integration.
