# SyberLabs homepage

Company and portfolio site for [syberlabs.io](https://syberlabs.io/).

Built with React and Vite on SyberLabs Design System v2 "Atlas": ink and vellum, a live Clifford-attractor plate behind the homepage hero, and a seeded de Jong sigil for each project. The kit lives in `kit/v2/` (`syber-atlas.css` tokens and components, `syber-atmosphere.js` plate engine, `syber-sigil.js` sigils; see `kit/v2/README.md`) and is published at [syberlabs.io/kit/v2/](https://syberlabs.io/kit/v2/), which is its canonical public home; product apps vendor a copy. `src/syberlabs.css` is the site layer on top of the kit. The homepage imports both, and the build emits them together at `/syberlabs.css` for the static pages. `node scripts/site-chrome.mjs` rewrites the shared header and footer into the static pages; CI runs it with `--check`, so a page whose chrome has drifted fails the build. Project data and navigation live in `projects/site-data.js`, shared by the homepage and the project pages. Run `pnpm install` and `pnpm build:site` to generate the full Cloudflare Pages output in `dist/`. The public RISE demo is copied into `dist/rise-demo/` by the deployment workflow.

The **System maps** components (`src/system-maps/`, not rendered on the homepage) draw Relay, OmniOS, RISE, Barn, OSAHR and SyberRuntime from their own repositories. Recorded traces in `src/*-trace.json` and `src/rise-record.json` are regenerated by the scripts in `scripts/`; `docs/SYSTEM_MAPS.md` records the evidence, commits and grades for every map.

Commons has one page, `/projects/commons/`, rendered from `projects/site-data.js` like the other projects. The earlier `/commons/` address redirects there (`_redirects`).

The current migration status lives in `kev/` and is published at `/kev/`. The prior Jev evaluation and integration case study remains at `/jev/` as historical evidence; its results must not be attributed to Kev.


The Sybershoke research note lives at `research/sybershoke/`. Revision 2 reports the Week 0 harness against its reference simulator (that repository is still unpublished), the public [SyberLabs/sybershoke](https://github.com/SyberLabs/sybershoke) workspace, and its first real system, the RISE Worker source run against recorded Jev answers; every number on it comes from that project's committed reports (`REPORT.md`, `docs/REDTEAM.md`, `docs/ADAPTER-RISE.md`), so update the note when they change.

The GrokCell Execution report lives at `research/jev-execution/`. It summarizes the durable offline prototype and its evidence limits; preserve the distinction between observed results and planned live integration.
