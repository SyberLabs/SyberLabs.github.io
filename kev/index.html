RISE · AI ARCHITECTURE · UPDATED OCTOBER 2026

Bring your own AI connection.

Optional AI features in RISE run strictly on connections you control: hosted Jev through your OpenRouter account, or pinned Kev-4B running locally on your GPU. RISE servers run no models and store no keys. Manual reading requires no AI.

Read the design note ↗

CURRENT STATUS

Established, shipped, and not adopted

  1. 01 / ESTABLISHED

    Bounded decision contract

    RISE builds finite choice menus from its public catalog, accepts answers only if every field matches an offered value, and applies reading settings deterministically. The same contract governs hosted Jev, local Kev, and evaluations.

  2. 02 / SHIPPED

    Shared inference retired

    The Cloudflare Worker serves only the app and static catalog; six legacy inference routes return HTTP 410 with setup guidance. OpenRouter connects via OAuth PKCE with keys kept strictly in tab memory and sent only to openrouter.ai. Local mode binds RISE and pinned Kev-4B to loopback with a per-run key invisible to the page.

  3. 03 / NOT ADOPTED

    Production Kev

    RISE intentionally runs no production Kev deployment. In internal evaluations, local Kev did not meet RISE’s quality threshold for reading requests (RISE task SCR-004, unpublished). Jev’s historical 48 of 49 preference score applies strictly to Jev, never Kev. Local Kev is tested on Windows (RTX 5080); Apple Silicon remains untested.
